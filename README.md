# 多媒體播放器

利用 Windows Media Player (WMP) 控制項製作的影音播放應用程式，提供直觀、穩定且具備彈性功能的影音觀看體驗。。


## 核心功能

### 1. 多格式相容播放

* 支援 `.mp4`、`.wmv`、`.avi` 等主流影音格式，並提供檔案瀏覽視窗方便使用者快速選取。
  
### 2. 精準播放控制：

* **播放/暫停**：即時切換播放狀態，保留觀看進度。

* **結束播放**：完全終止播放並重設影片至起始點。

* **快進與倒退**：具備 ±5 秒 的快速跳轉功能，方便使用者定位想要觀看的片段。

* **多段倍速調整**：利用 TrackBar 提供 x0.75、x1.0、x1.25、x2.0 四種播放速率，滿足各種瀏覽需求。

### 4. 操作安全機制：

* **畫面縮放**：透過 Dock 與 Anchor 屬性優化，無論視窗如何縮放，播放畫面與控制面板皆能保持正確比例。

* **提醒視窗**：具視窗關閉確認對話框，防止使用者因誤觸而導致播放中斷。

### 5. 無滑鼠操作：

* 全程支援 `tab 鍵` 跳轉與 `空白鍵` 選取。


## 使用說明

以下為預設視窗介面：

1.  **載入媒體**：
   
    * 啟動程式後，點擊 `瀏覽檔案` 按鈕選取影音檔，檔案載入後預設為停止狀態。
  
    * 以下是點擊瀏覽檔案後應出現畫面，提供四種格式的影音檔可選擇：

      <img width="500" alt="螢幕擷取畫面 2026-05-13 151412" src="https://github.com/user-attachments/assets/81704c97-b128-407d-8eb3-f6507cf04839" />

2.  **開始觀看**：
   
    * 按下 `播放` 按鈕開始收看影片；如需暫時停止但保進度請點擊 `暫停`。

3.  **調整進度與速度**：
   
    * 點擊「快進 5 秒」或「倒退 5 秒」調整目前位置。

    * 用滑鼠或鍵盤左右鍵控制下方的進度滑桿（TrackBar）即可即時變更播放倍速 `x 0.75`、`x 1.0`、`x 1.25`、`x 2.0`（預設為 x 1.0 正常速度）。

4.  **結束播放**：

    * 若使用者要更換影音檔可以先按下 `結束播放` 讓影片停止並重置到起始位置。

6.  **結束程式**：
      
    * 按下視窗右上角的「X」，會彈出確認視窗，避免使用者誤按，若要關閉程式按「是(Y)」即可結束。
